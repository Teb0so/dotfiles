# My dotfiles and configurations for the programs I use.

### Usage

To deploy my configurations run the `deploy.sh` script, but make sure make a configuration file declaring the configuration modules you intend to use, to create a configuration create a file on the root of this repository called: `config_<your-computer-hostname>.sh`, if there is no config file matching your computer hostname, then `deploy.sh` will use the `config_default.sh` configuration.
